# Лабораторна робота №1 — Теорія алгоритмів (варіант 4)

Тема: створення і компіляція консольного проєкту за допомогою .NET CLI, модульні тести MSTest.

* `ConsoleApp1` — приклад з методички: сума двох чисел; `ConsoleApp1.Tests` — тест 5 + 6 = 11.
* `Lab1_Variant4` — індивідуальне завдання: Об'єм та площа поверхні прямокутного паралелепіпеда (a, b, c).
* `Lab1_Variant4.Tests` — модульні тести за контрольним прикладом.

Запуск:

```
dotnet run --project Lab1_Variant4
dotnet test
```
